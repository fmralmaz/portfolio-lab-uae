# PortfolioLab UAE

### Educational Investment Portfolio Simulator

PortfolioLab UAE is an educational investment portfolio simulator designed to help students understand **diversification, risk, asset allocation, and compound growth** through an interactive experience.

The simulator starts with a fictional **AED 100,000 portfolio** and allows users to choose how much to allocate to stocks, bonds, gold, and cash.

## Why I Built This

I built PortfolioLab UAE as my second FinTech and finance project to explore how investment portfolios work.

Instead of only explaining investing through text, I wanted to create something interactive where students can change their portfolio allocation and immediately see how the estimated return, risk level, and portfolio growth change.

## Features

- Fictional AED 100,000 starting portfolio
- Adjustable allocation for:
  - Stocks
  - Bonds
  - Gold
  - Cash
- Conservative, Balanced, and Growth presets
- Automatic estimated portfolio return
- Estimated profit/loss
- Portfolio risk indicator
- Visual asset allocation breakdown
- 5-year compound growth projection
- English and Arabic language support
- Arabic right-to-left interface
- Responsive design for different screen sizes

## How It Works

The simulator uses fictional annual return assumptions for each asset category:

- Stocks: 8%
- Bonds: 4%
- Gold: 5%
- Cash: 2%

The portfolio's estimated return is calculated based on the percentage allocated to each asset.

For example, a portfolio with a larger allocation to stocks will generally produce a higher estimated return in this simulator, but will also be assigned a higher risk level.

The simulator also uses compound growth to show how the portfolio could change over five years if the estimated return remained constant.

**These assumptions are fictional and are used only for educational purposes.**
